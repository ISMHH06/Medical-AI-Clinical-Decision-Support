# Medical AI & Clinical Decision Support

An end-to-end multimodal medical AI decision-support system that combines
chest X-ray imaging and clinical information for disease prediction,
explainability, uncertainty estimation, and robust evaluation.

## Project Status

🚧 Active Development

## Overview

This project aims to develop a multimodal AI system capable of analyzing
chest X-ray images together with available clinical information to assist
in the assessment of thoracic abnormalities.

The system focuses not only on predictive performance, but also on:

- Multimodal learning
- Explainability
- Uncertainty estimation
- Model calibration
- Robustness
- Bias and subgroup analysis
- Error analysis
- External validation
- Real-world deployment
